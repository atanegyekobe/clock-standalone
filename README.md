# GHANAMAN TV Clock and Program Lineup

This folder is a standalone React/Vite project. To move it into a new project, copy the entire `clock-standalone` folder contents.

With Node.js 26 installed, run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` to create a production build.

The clock uses the `Africa/Accra` timezone. The weekday program entries and Thursday note are maintained in `src/ClockApp.jsx`.
